# TG голос — примеры «до и после»

> Копилка для обучения боди (/tg-content) голосу Эдди. Каждая пара: каркас ИИ → финал Эдди → разбор приёмов.
> Правило: с каждым докрученным постом добавлять сюда пару.

## Пример 1: япинг про документацию (23.08.2026)

**До (каркас ИИ):** нейтральная подача «Открываю документацию... 40 страниц» — взгляд сверху, абстрактные примеры, «я»-перформанс.

**После (финал Эдди):** хук «Никто не читает документацию. И я знаю почему» → общая боль через «ты» → живые рабочие детали (бизнес-суть в доке эндпоинта, id из существующей сущности БД) → JSON с комментами как аргумент → самоирония «обжёгся на собственных эссе» → категоричная триада финала → вопрос.

**Приёмы, которые вынесены:**
1. Хук-интрига с обещанием ответа, а не констатация
2. Общая боль через «ты» вместо «я»-перформанса (сноб → свой парень)
3. Реальные детали из своей работы вместо абстрактных примеров
4. Наглядный аргумент (JSON с комментами) вместо слов
5. Самоирония-признание («сам так писал») — главный антисноб
6. Категоричность в сути, не в позе; тезисы без воды («Пример — обязателен ВСЕГДА»)
7. Лишнюю тему урезать до тизера («но это отдельная тема») — задел на серию

## Идеи на потом (из обсуждения)

- Гайд «как писать нормальную доку» — ресёрч небулщит-гайдов в сети + свой гайд как лид-магнит (в парковке хаба)
