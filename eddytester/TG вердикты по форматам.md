## Новые форматы (свои, из данных + интересов Эдди)

Данные: шпаргалка=репосты, интерактив=комменты, разборы http-api заходят, продающие посты дают реакций 28.8.
Интересы: бэкенд-разборы, нишевые лайфхаки, мнение+комменты. Бюджет: ~2 ч/нед.

### 1. «Нишевый лайфхак» — флагман (1/нед)
Один инструмент/приём, который мало кто знает, с живым примером из своей работы.
Обоснование: тема инструменты = 🔁18.5; формат шпаргалка = 🔁31.5. Это их скрещивание.
Пример: «Тело в GET-запросе» уже сработал (56 реакций) — та же ДНК.

### 2. «Баг из практикума» — продажа через игру (1/2 нед)
Запрос → ответ v1 → ответ v2 → «что не так?». Разбор на следующий день.
Обоснование: продающие посты дают реакций 28.8 (аудитория откликается!), интерактив 👁797.
Это закулисье продукта + механика угадай-баг + продажа без продажи.

### 3. «Мнение на 5 строк» — коммент-магнит (1/нед)
Позиция по спорному вопросу + вопрос в конце. Минимум труда, максимум обсуждения.
Обоснование: холивар реакций 18.9; Эдди хочет «мнение + комменты на регулярность».

### 4. «Чужой баг-репорт под микроскопом» (1/2 нед)
Разбор реального плохого баг-репорта: что не так → как надо.
Обоснование: разбор = 🔁9.9, реакций 14.7; живой материал, учит аудиторию + показывает экспертизу.

### 5. «Баги в проде #N» — еженедельный сериал-лайт (1/нед, вместо BSA-сериала)
Короткая история одного прод-бага. Продолжение-ожидание, но без марафона.
Обоснование: сериал реакций 23.5, сторителлинг 👁851, 🔁9.2. Была серия #414 «Баги в проде №1» — продолжение брошено, подписчики ждут.

## Что не доказано и стоит проверить

- Комменты в наших данных отсутствуют — метрика продаж считается косвенно (реакции). Настроить выгрузку комментов перед ставкой на «мнение».
- Эффект времени публикации: 06–07 МСК лучшее по просмотрам — но посты тех лет могли попадать в другое время по другим причинам. A/B на паре недель.
