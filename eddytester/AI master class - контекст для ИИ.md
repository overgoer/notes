# Контекст для ИИ: мастер-класс «ИИ для тестировщика»

> Назначение: в начале новой ИИ-сессии укажи на этот файл (или скопируй его в промпт) — ИИ сразу поймёт цель, задачи и что уже исследовано. Не нужно объяснять с нуля.

## Проект

Эдди готовит прямой эфир / мастер-класс для тестировщиков: как использовать ИИ в личных и рабочих целях. Подход — **no bullshit**: без хайпа про «AI заменит тестировщиков», только реальные инструменты, которые работают из РФ бесплатно или за копейки.

**Позиционирование:** AI — бесплатный младший коллега, если знать как его подключить.

## Аудитория

Junior QA и тестировщики, которые тестировали только фронт. Большинство из РФ: критично помечать, что работает без VPN, а что только с VPN.

## Личный стек Эдди (факты для живых демо, не выдумывать)

- 90% работы с ИИ — в терминале
- Claude Code + DeepSeek через прокси (claude-code-router / cc-switch)
- Gemini CLI на фритире AI Studio через свой launchd-туннель (SSH SOCKS 1080 → HTTP 8080, переживает смену Wi-Fi)
- llm CLI (Simon Willison) в пайпах
- Свой учебный API-проект v0-test-api — методология v1/v2 («ответ модели = гипотеза, эталон = дока»)

## Что уже исследовано и зафиксировано

1. **Структура эфира (75–90 мин):** интро (5) → инструменты по задачам (15) → поиск и картинки → скиллы (10) → модели (5) → корона: бесплатный Claude-like в РФ (25) → ограничения/приватность (5) → демка + Q&A (10)
2. **Инструменты по задачам:** PDF — Gemini/AI Studio, NotebookLM, Docling/Marker; Excel — CSV/Markdown вместо xlsx; доки — Swagger в AI Studio, llm CLI; код — Claude Code, Gemini CLI, Cline/Roo, Trae, Aider, Copilot Free
3. **Поиск:** встроенный в чатах (DeepSeek, Qwen, Gemini grounding); SearXNG + MCP-searxng; готовые MCP: Tavily, Brave, Firecrawl; Gemini CLI с grounding
4. **Картинки из РФ:** Fusion Brain, Shedevrum/Yandex ART, SiliconFlow, Pollinations, Bing Image Creator, локально Draw Things (Mac) / Fooocus (Win)
5. **Корона — 4 уровня бесплатного Claude-like в РФ:** чаты без VPN → бесплатные API (AI Studio, GitHub Models, NVIDIA NIM, Cloudflare Workers AI, OpenRouter :free) → копеечные (DeepSeek off-peak) → терминал-агенты (claude-code-router, Gemini CLI, llm, aichat)
6. **No bullshit-блок:** галлюцинации, NDA/приватность (Ollama локально для конфиденциального), reasoning не нужен везде
