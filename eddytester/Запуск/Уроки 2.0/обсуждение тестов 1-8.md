## Техническая справка (как это работает)

**Связка фронт ↔ бэк:**
- Бэкенд: `v0-test-api/src/routes/progress.js` → `LESSONS_CONFIG` — источник истины: вопрос, варианты (`bugs: [{id, name}]`), правильные (`correct: [ids]`), заголовки, подсказки
- Фронтенд: `page101922726.html` → `LESSON_MAP` (блок страницы `lN` → `lesson_id` бэка) + `renderTest()` рисует чекбоксы из того, что отдал бэк
- Итого: новый тест = 1 запись в `LESSONS_CONFIG` (бэк) + 1 строка в `LESSON_MAP` (фронт)

**Механика зачёта (строгая, без частичного зачёта):**
- Пройден = отмечены ВСЕ правильные + НЕ отмечен ни один неправильный
- Поля теста: `testTitle`, `testSubtitle`, `successMsg`, `hintMsg`, `correct[]`, варианты
- Тип `quiz` (вопрос-викторина) — для теории; без типа — «найди баги» (для практики, уроки 9+)
