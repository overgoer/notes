## 🎬 Урок 1. Введение в API Practicum

### 📝 Что раскрывается в видео (Содержание урока)
1. **Знакомство и цели**: Что такое API Practicum, из чего он состоит, что студент получит на выходе. Убираем страх перед первым тестированием API.
2. **Практическая ценность**: Студенту предстоит самостоятельно найти **более 40 реальных багов** в API стенде. Главное — не просто показать баги, а научить студента видеть принципы их выявления.
3. **Разбор теории и артефактов**: Написание тест-кейсов и оформление баг-репортов. Эдди лично проверяет тест-кейсы студентов и даёт правки.
4. **Шаблоны**: Студенты получат готовые и понятные шаблоны для написания тест-кейсов и баг-репортов.
5. **Инструменты обучения**:
   * **Страница обучения (Хаб)**: Главный центр знаний, видео, полезные ссылки, задания и тесты.
   * **Postman**: Основной инструмент тестирования API (установка в первых уроках).
   * **Документация**: Техническое задание и недостижимый эталон (контракт), по которому мы сверяем работу API.
   * **Шпаргалка по багам** и **База данных PostgreSQL** (будут рассмотрены позже).
6. **Комьюнити и Поддержка**:
   * **Telegram-чат** для общения студентов, обмена опытом и взаимопомощи.
   * **Личные контакты автора** (Telegram-личка, Email) для тех, кто стесняется писать в общий чат.
7. **Первый шаг**: Пройти первый супер-простой тест под видео и переходить к следующему уроку.

### ❓ Проектирование тестов для Урока 1

Давай выберем лучший формат теста. Вот 3 классных варианта:

#### Вариант А: Игровой / Шуточный (Как на старом сайте, но более структурированный)
* **Вопрос**: Какое секретное оружие упоминалось в этом уроке как твой главный инструмент для борьбы с вредоносными багами? Отметь правильные варианты:
  * [ ] Меч Элронда из Властелина Колец
  * [x] **Программа Postman для отправки запросов** *(Правильно)*
  * [x] **Подробная документация API (наш контракт)** *(Правильно)*
  * [ ] Кофеварка на 1.5 литра для ночных сессий
  * [x] **Общий студенческий чат в Telegram** *(Правильно)*

#### Вариант Б: Практический и профессиональный (Рекомендуемый)
* **Вопрос**: Какие инструменты, материалы и каналы связи станут твоими главными ориентирами на протяжении всего практикума? Отметь все верные варианты:
  * [x] **Документация API как эталон и техническое задание** *(Правильно — учит читать доку)*
  * [ ] Курс по дизайну интерфейсов в Figma
  * [x] **Инструмент Postman для взаимодействия с сервером** *(Правильно — основной инструмент)*
  * [x] **Шаблоны тест-кейсов и баг-репортов от Эдди** *(Правильно — снижает когнитивную нагрузку)*
  * [x] **Поддержка в Telegram-чате курса или напрямую у автора** *(Правильно — снимает барьер общения)*

#### Вариант В: Фокус на целях обучения
* **Вопрос**: Что тебе предстоит сделать на пути к финалу API Practicum? Отметь то, о чём Эдди говорит в уроке:
  * [x] **Самостоятельно выявить принципы нахождения частых багов в API** *(Правильно)*
  * [ ] Написать и закодить собственную базу данных на Node.js
  * [x] **Найти более 40 реальных заложенных багов в API** *(Правильно)*
  * [x] **Оформить тест-кейсы и баг-репорты по готовым шаблонам** *(Правильно)*

### 💬 Моё предложение как Проджект-Менеджера:
