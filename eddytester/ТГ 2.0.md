### Скептическая переоценка майского наследия

1. **Майская система не выжила.** «3 поста/нед — жёсткая норма» + 44 готовых поста → к августу канал замолчал. Вывод: система требовала больше энергии, чем было. Новую систему строим под НИЗКУЮ энергию.
2. **Противоречие пропорций:** v6 и Цели канала говорят 50/30/20, Мастер-стратегия и CONTENT.md — 70/20/10. Не спорить, а посчитать по данным: какая доля продающих постов в топе по энгейджменту.
3. **Форматы не проверены фактами.** 10 форматов писались в мае. Теперь есть полная выгрузка с метриками — каждый формат проверяем: применялся ли, как отработал.
4. **Энергозатратные форматы под подозрением:** сериал (10 дней подряд), скринкаст (2/нед). При выгорании — первые кандидаты на вылет.
5. **Цели роста (5000 подписчиков) — не сейчас.** Сначала регулярность + качество, потом рост.

### Что из наследия забираем без пересмотра

- Формула крючка: **личное отношение → конкретный опыт → польза** ([[_ГОЛОС_И_ТЕМЫ_2026-05-25]])
- Правило одного поста: у поста ровно одна цель — научить / вовлечь / продать
- Запрет: без кликбейта, без «ТОП-10», без «90% тестировщиков не знают»
- Score-формула: views×0.5 + fwd×0.2 + reacts×0.2 + replies×0.1 ([[TG топ посты]])
