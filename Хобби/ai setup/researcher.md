## 🔍 Детальный разбор кандидатов

### 🏆 #1. GPT Researcher (`assafelovic/gpt-researcher`)
> **Абсолютный лидер для автономного написания глубоких, структурированных отчетов по любой теме.**

*   **Что делает:** Берет поисковый запрос, разбивает его на 10-15 подзадач, параллельно ищет по веб-источникам (через Tavily, Serper, Bing, Google или бесплатный SearxNG), скрейпит контент, очищает от мусора, фильтрует релевантность и генерирует огромный структурированный PDF/Markdown отчет (2000+ слов) со ссылками на источники.
*   **Связка с DeepSeek:** Нативно поддерживает DeepSeek-V3 (`deepseek-chat`) и DeepSeek-R1 (`deepseek-reasoner`). Позволяет использовать дешевую/быструю модель для парсинга и планирования, а сильную (R1) — для написания финального отчета, что делает его **очень гибким**.
*   **Сложность установки:** **Легкая**. Разворачивается за 3 минуты либо через простой `pip install gpt-researcher` в виртуальное окружение, либо одной командой `docker compose up -d`. Есть как CLI-интерфейс, так и готовый современный Web UI на React/Python.
*   **Надежность:** **Исключительная**. Самый стабильный, mature-проект в нише (17k+ звезд), активно поддерживается и имеет подробную документацию.
*   **Что пишут пользователи:** *"Самое зрелое решение на рынке. Если вам нужен готовый, глубокий отчет со списком литературы и цитатами, а не просто быстрый ответ в чате — этот инструмент превосходит любые аналоги."*

### 🥈 #2. dzhng/deep-research (`dzhng/deep-research`)
> **Лучший сверхлегкий агент, созданный как прямая альтернатива OpenAI Deep Research.**

*   **Что делает:** Настоящий итеративный агент глубокого поиска. Он сначала задает вам уточняющие вопросы, строит граф исследования, затем последовательно "копает" интернет в несколько кругов (до 5-7 уровней вложенности), находит неочевидную информацию и выдает цельный аналитический отчет.
*   **Связка с DeepSeek:** Спроектирован с фокусом на использование **DeepSeek-R1** в качестве "мыслящего ядра". Шаги рассуждения (Chain of Thought) R1 идеально ложатся на его архитектуру глубокого погружения.
*   **Сложность установки:** **Легкая**. Написан на TypeScript / Node.js. Требует Node.js, `npm install`, указания ключей API (DeepSeek, Firecrawl и др.) и запускается простой командой в консоли.
*   **Надежность:** **Средняя** (проект свежий, вирусно взлетел до 12k+ звезд за пару недель). Потребуются небольшие настройки поискового бэкенда (лучше всего работает с Firecrawl API).
*   **Что пишут пользователи:** *"Вирусный хит. Алгоритм итеративного углубления поиска работает невероятно круто. Он действительно находит то, что обычный поиск упускает. Настоящий Deep Research на вашем сервере."*

### 🥉 #3. Perplexica (`ItzCrazyKns/Perplexica`)
> **Лучший выбор, если вам нужен красивый веб-интерфейс "вопрос-ответ" (замена Perplexity) для ежедневной работы.**

*   **Что делает:** Работает как полноценная поисковая система с ИИ. Быстро ищет ответы в вебе, группирует их, подкрепляет источниками и выдает лаконичный интерактивный ответ в реальном времени. Имеет "фокус-режимы" (Академический, Код, YouTube, Reddit).
*   **Связка с DeepSeek:** Полная поддержка DeepSeek. Вы можете выбрать DeepSeek API прямо в меню настроек UI или прописать в `config.toml`.
*   **Сложность установки:** **Легкая**. Поставляется с готовым `docker-compose.yml`, который сразу поднимает и сам поисковик, и локальный приватный поисковый движок **SearxNG**. Не требует покупки платных поисковых API (Tavily/Serper), что делает работу **полностью бесплатной** в плане поиска.
*   **Надежность:** **Высокая**. Проект проверен временем (15k+ звезд), работает быстро и без сбоев.
*   **Что пишут пользователи:** *"Идеальный клон Perplexity. Интерфейс безумно удобный. То, что SearxNG идет в комплекте, экономит кучу денег на поисковых API."*

### 🏅 #4. Stanford STORM (`stanford-oval/storm`)
> **Академический гигант для автоматического создания статей Википедии и подробных обзоров.**

*   **Что делает:** Имитирует процесс написания академической статьи: создает экспертные точки зрения (персоны), проводит виртуальное "интервью" между ними (сам задает вопросы и сам находит ответы в поиске), формирует скелет статьи (Outline) и пишет академический лонгрид.
*   **Связка с DeepSeek:** Поддерживает через библиотеки `dspy` / `litellm`. Рекомендуется использовать `deepseek-chat` для фазы вопросов и `deepseek-reasoner` (R1) для итогового академического структурирования.
*   **Сложность установки:** **Средняя**. Это скорее Python-библиотека/фреймворк, требующая написания небольшого скрипта для запуска или кастомизации под свои нужды.
*   **Надежность:** **Средняя**. Так как проект родом из Stanford OVAL, он больше ориентирован на исследования, а не на легкий запуск в продакшене. Требует надежных платных поисковых ключей (Bing/Serper).
*   **Расход токенов:** **Высокий**. Из-за сложной схемы DSPy (диалогов персон) тратит очень много токенов на один запрос.
*   **Что пишут пользователи:** *"Генерирует невероятно глубокие и научно оформленные лонгриды, но настройка и поддержание стабильности требуют усилий. Не для быстрого запуска."*
