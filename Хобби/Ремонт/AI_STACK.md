# AI-стек для анализа ремонта

> Технический справочник. Как пользоваться AI-инструментами для анализа дизайн-проекта.

---

## Инструмент 1: pdftotext (текстовый слой PDF)

**Зачем:** Archicad сохраняет размеры, метки и спецификации как текст внутри PDF. pdftotext извлекает их мгновенно и бесплатно.

```bash
# Извлечь весь текст
pdftotext "НОВОЕ ОЧАКОВО (2).pdf" full-text.txt

# Извлечь конкретные страницы (12-29 — технические листы)
pdftotext -f 12 -l 29 "НОВОЕ ОЧАКОВО (2).pdf" technical-sheets.txt
```

**Когда использовать:** всегда первым делом. Даёт точные цифры.

## Инструмент 2: Vision API (OpenRouter)

**Зачем:** Анализировать планы и развёртки как изображения. Понимает пространственные отношения, видит что нарисовано.

**Скрипт:** `~/IdeaProjects/v0-test-api/scripts/vision.js`

```bash
# Базовый вызов
OPENROUTER_API_KEY="sk-or-v1-..." \
node ~/IdeaProjects/v0-test-api/scripts/vision.js \
  --image page-12.jpg \
  --model google/gemini-2.5-flash \
  --max-tokens 3000 \
  --prompt "Опиши этот план. Все размеры, все помещения."

# С промптом из файла
OPENROUTER_API_KEY="sk-or-v1-..." \
node ~/IdeaProjects/v0-test-api/scripts/vision.js \
  --image page-12.jpg \
  --prompt-file questions.txt
```

**Ключ API:** лежит в `~/.claude/settings.local.json` (поле `OPENROUTER_API_KEY`)

### Выбор модели

| Ситуация | Модель | Почему |
|----------|--------|--------|
| Быстрый вопрос по странице | `google/gemini-2.5-flash` | Дёшево ($0.008), быстро |
| Сложный пространственный анализ | `openai/gpt-4o` | Лучше понимает чертежи |
| Финальная валидация важного решения | `anthropic/claude-sonnet-4` | Самый внимательный к деталям |
| Исчерпали бюджет на Flash | `google/gemini-2.5-pro` | Бесплатно 50/день |

### Стоимость (ориентир)

- 1 анализ страницы Gemini Flash: **$0.008** (меньше цента)
- Полный анализ 18 листов: **~$0.15**
- Перекрёстные проверки: **~$0.25**
- Финальное заключение (Claude): **~$0.25**
- **Итого полный цикл: ~$0.71**

## Инструмент 3: Извлечение страниц как изображений

```bash
# Одна страница, 250 DPI (хорошо для vision)
pdftoppm -jpeg -r 250 -f 12 -l 12 "НОВОЕ ОЧАКОВО (2).pdf" page-12

# Все технические страницы (12-29)
for i in $(seq 12 29); do
  pdftoppm -jpeg -r 200 -f $i -l $i "НОВОЕ ОЧАКОВО (2).pdf" "page-$(printf '%02d' $i)"
done
```

## Рабочий процесс (рекомендуемый)

```
1. pdftotext → извлечь весь текст
2. pdftoppm → извлечь ключевые страницы как JPEG
3. Vision API → анализ каждой страницы
4. Человек + AI → перекрёстная сверка листов
5. Vision API (Claude) → финальная валидация критических мест
6. SESSION_LOG.md → записать все выводы
```
